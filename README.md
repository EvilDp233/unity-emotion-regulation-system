# 基于Unity的情绪调控虚拟交互系统

## 一、项目简介

本项目为华南师范大学软件工程专业本科毕业设计。

项目拟基于 Unity 开发一个情绪调控虚拟交互系统，通过虚拟场景、交互任务和情绪调控活动，为用户提供具有一定沉浸感的情绪调控体验。

系统重点关注情绪调控相关实验范式、虚拟环境设计、人机交互以及情绪调控效果记录。

## 二、项目目标

完成一个具有完整交互流程的 Unity 情绪调控虚拟交互系统，包括：

- 用户进入系统
- 情绪状态测评
- 情绪调控活动
- 虚拟环境交互
- 调控过程数据记录
- 调控后的再次测评
- 结果展示

## 三、技术路线

- Unity
- C#
- Unity UI
- 场景管理
- 人机交互
- 数据记录
- JSON / CSV 等数据存储方式

暂不考虑复杂的 EEG 情绪识别、复杂机器学习模型等高风险技术。

## 四、研究方向

1. 情绪调控
2. 虚拟现实与虚拟环境
3. 人机交互
4. 游戏化/交互式情绪干预
5. Unity 虚拟交互系统

## 六、项目原则

- 优先保证毕业设计能够完整实现
- 避免不必要的技术复杂度
- 功能逐步开发
- 每个功能完成后进行测试
- 保留开发过程和测试记录
- 保证论文与实际系统保持一致
