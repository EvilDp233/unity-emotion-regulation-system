# 系统功能模块划分

## 1. 用户管理模块
- 用户注册/登录
- 用户信息管理
- 使用记录管理

## 2. 情绪评估模块
- 前测：使用前情绪状态自评
- 后测：使用后情绪状态自评
- 情绪维度：焦虑水平、压力感知、情绪效价等
- 评估量表：可视化评分（1-10分）

## 3. 情绪调控训练模块

### 3.1 呼吸训练子模块
- 4-7-8呼吸法引导
- 腹式呼吸训练
- 可视化呼吸动画

### 3.2 正念冥想子模块
- 引导式冥想音频
- 计时训练
- 专注力引导

### 3.3 自然场景沉浸子模块
- 森林场景
- 海边场景
- 花园场景
- 环境音效

### 3.4 音乐放松子模块
- 放松音乐播放
- 音量调节
- 音乐切换

## 4. 交互小游戏模块
- 放松主题小游戏
- 正向反馈机制
- 难度渐进

## 5. 数据记录模块
- 情绪评分记录
- 训练历史记录
- 数据导出功能
- 趋势可视化

## 6. 系统设置模块
- 音效设置
- 画面设置
- 语言设置
- 隐私设置

## 模块关系图

```
用户
  │
  ├──→ 情绪评估（前测）
  │         │
  │         ↓
  ├──→ 情绪调控训练
  │       ├── 呼吸训练
  │       ├── 正念冥想
  │       ├── 自然场景
  │       ├── 音乐放松
  │       └── 小游戏
  │         │
  │         ↓
  ├──→ 情绪评估（后测）
  │
  └──→ 数据记录与展示
```
