# Unity 场景管理

## 场景切换

### 基础用法
```csharp
using UnityEngine.SceneManagement;

// 按名称加载场景
SceneManager.LoadScene("SceneName");

// 按索引加载场景
SceneManager.LoadScene(0);

// 异步加载（带加载界面）
AsyncOperation operation = SceneManager.LoadSceneAsync("SceneName");
```

### 场景切换流程（本系统）
```
默认场景 → 主页场景 → 功能选择 → 子场景
                               ├── 呼吸训练场景
                               ├── 冥想训练场景
                               ├── 自然探索场景
                               ├── 小游戏场景
                               └── 情绪评估场景
```

## 加载界面实现
- 使用 `SceneManager.LoadSceneAsync()`
- 配合 Slider 显示加载进度
- 加载完成后自动跳转

## 场景设置
- Skybox：环境天空盒设置
- Lighting：全局光照设置
- NavMesh：导航网格烘焙
