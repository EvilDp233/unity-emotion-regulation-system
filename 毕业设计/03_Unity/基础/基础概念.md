# Unity 基础概念

## 核心概念

### Scene（场景）
- Unity中的场景是游戏/应用的独立关卡或状态
- 每个场景包含GameObject、灯光、摄像机等元素
- 使用 `SceneManager.LoadScene()` 切换场景

### GameObject（游戏对象）
- Unity中的基本实体对象
- 所有物体都是GameObject
- 通过添加Component赋予功能

### Component（组件）
- 定义GameObject的行为和属性
- 常见组件：Transform, Renderer, Collider, Rigidbody
- 自定义组件通过继承 MonoBehaviour 实现

### Prefab（预制体）
- 可复用的GameObject模板
- 可在场景间重复使用
- 修改Prefab可同步更新所有实例

### Transform（变换）
- 每个GameObject都有的基础组件
- 包含位置（Position）、旋转（Rotation）、缩放（Scale）

## 关键组件

| 组件 | 用途 |
|------|------|
| Camera | 渲染场景视图 |
| Light | 场景照明 |
| Canvas | UI布局基础 |
| Animator | 动画控制 |
| AudioSource | 播放音频 |
| Terrain | 地形生成 |

## 常用操作
- 创建对象：`GameObject.CreatePrimitive()`
- 查找对象：`GameObject.Find()`, `FindObjectOfType<>()`
- 获取组件：`GetComponent<>()`
- 添加组件：`AddComponent<>()`
