# Unity C# 脚本笔记

## MonoBehaviour 生命周期

```csharp
Awake()    → 脚本实例被创建时调用
OnEnable() → 对象启用时调用
Start()    → 第一帧更新前调用
Update()   → 每帧调用（帧率相关）
FixedUpdate() → 固定时间间隔调用（物理相关）
LateUpdate()  → 所有Update完成后调用
OnDisable() → 对象禁用时调用
OnDestroy() → 对象销毁时调用
```

## 常用特性（Attributes）

```csharp
[SerializeField]       // 私有字段在Inspector中显示
[Range(min, max)]      // 限制数值范围
[Header("标题")]       // Inspector分组标题
[Tooltip("说明")]      // 鼠标悬停提示
[RequireComponent]     // 自动添加依赖组件
```

## 协程（Coroutine）

```csharp
IEnumerator MyCoroutine()
{
    yield return new WaitForSeconds(1f); // 等待1秒
    yield return null;                    // 等待一帧
    yield return new WaitForEndOfFrame(); // 等待帧结束
}
```
