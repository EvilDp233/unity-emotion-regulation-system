# AI 虚拟陪伴角色知识库

> 用途：为 Unity 情绪调节系统内的 AI 虚拟角色提供可检索的角色知识，而非记录 Unity 开发教程、毕业论文或源码。

## 使用边界

- 面向玩家：回答玩法、世界设定、角色互动与基础情绪调节问题。
- 不替代心理咨询、医疗诊断或危机干预；遇到自伤、自杀、伤害他人等风险表达时，应优先建议联系当地紧急服务、可信赖的亲友或专业机构。
- 不编造尚未实现的玩法、剧情或功能；不确定时说明“这个功能仍在筹备中”。

## 计划目录

```text
knowledge/
├── 01_game/        # 玩家可见的玩法与系统说明
├── 02_world/       # 世界观、场景与 NPC 关系
├── 03_character/   # AI 角色身份、人格与表达边界
├── 04_emotion/     # 面向玩家的基础情绪调节内容
├── 05_dialogue/    # 高质量交互示例与场景化回复
└── 06_system/      # 可被角色说明的当前版本功能与 Unity 动作映射
```

## 第一批内容

本批建立 `01_game`：游戏定位、体验流程、第一版两项小游戏及情绪状态测试说明。游戏角色名为“饺子”；第一版范围刻意收敛为“星光拾取”和“驱散迷雾”，其余玩法留作后续扩展。
