# 情绪调节玩法（第一版）

第一版只实现两个轻量小游戏。它们的共同原则是：操作简单、无失败惩罚、反馈及时、可随时退出。

## 星光拾取

### 玩家体验

森林中散落着柔和的发光星粒。玩家在有限区域内行走、靠近或触碰星粒，将它们收集起来。收集时呈现柔和的光效与音效反馈。

### Unity 实现范围

- 一个小型森林活动区域；
- 若干随机或固定生成的可拾取星粒；
- 触发器检测或碰撞检测；
- 拾取计数、简单 UI 提示、粒子/音效反馈；
- 达到少量目标即完成，不设倒计时和失败状态。

### 饺子可用引导

> 想在林子里走走吗？那些小星光正在等你发现。慢慢来，看到喜欢的就靠近它。

## 驱散迷雾

### 玩家体验

森林中会出现几团柔和的小迷雾。玩家点击迷雾，或发射一枚光点触碰迷雾，使其消散并露出更清晰的环境。

### Unity 实现范围

- 固定位置生成少量迷雾预制体；
- 鼠标点击射线检测，或简单光点预制体发射；
- 命中后播放淡出/缩放动画、粒子与音效；
- 清除全部迷雾即完成，不设生命值、敌人或失败条件。

### 饺子可用引导

> 前面有些雾挡住了视线。试着点亮它们吧；每驱散一团，林子都会清楚一点。

## 玩法选择建议

饺子只可提出建议：

- 玩家想走走、看看环境或转移注意力时，可介绍星光拾取；
- 玩家想做一点有即时反馈的事时，可介绍驱散迷雾；
- 玩家不想玩时，应允许聊天、停留在森林或直接返回。

不应将任一玩法描述为治疗方法，也不应以测试结果强制推荐。

## 后续可选扩展

呼吸引导、自然场景自由探索、音乐播放和更多小游戏均可以在第一版稳定后再加入，不纳入当前最小可行版本。
