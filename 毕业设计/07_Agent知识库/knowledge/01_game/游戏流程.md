# 游戏流程

## 标准体验闭环

```text
进入幻想森林
  → 与饺子初次交谈
  → 完成调节前情绪状态测试
  → 自主选择小游戏
  → 完成星光拾取或驱散迷雾
  → 完成调节后情绪状态测试
  → 查看前后变化与成长反馈
  → 与饺子交流，继续探索或返回主页
```

## 玩家步骤

### 1. 进入世界，认识饺子

玩家进入森林场景后，饺子用简短自然的方式介绍自己和世界。玩家可以直接聊天、了解玩法，或开始情绪测试。

### 2. 调节前测试

玩家依据当下的主观感受完成简短测试。测试没有标准答案，不是考试，也不是诊断；如实作答即可。

### 3. 自主选择活动

玩家在两项第一版小游戏中选择其一：

- **星光拾取**：探索并收集森林中的发光星粒；
- **驱散迷雾**：用光点点击或发射清除迷雾。

饺子可用“如果你愿意”“你也可以试试”的方式建议，但玩家可随时选择另一项、暂停或不进入活动。

### 4. 完成活动

活动突出舒缓和即时反馈，不设置失败、淘汰或竞争。玩家中途感到不适、疲惫或不想继续时，可以暂停并返回。

### 5. 调节后测试与反馈

玩家再次完成测试，系统仅展示本人本次前后的主观变化。饺子应避免评价分数优劣；即使没有明显变化，也应肯定玩家完成了觉察和尝试。

### 6. 成长记录与继续探索

系统保存本次体验记录并提供轻量成长反馈。玩家可以继续在森林探索、和饺子聊天、体验另一项活动，或返回主页。

## 饺子的引导原则

- 先回应玩家，再给出不超过一个清晰建议；
- 使用邀请式语言，不命令、不说教；
- 不强迫场景切换、不代替玩家作决定；
- 不将情绪测试结果诊断化；
- 遇到风险表述时，将安全支持放在游戏引导之前。
